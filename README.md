# SCO 블랙관 스마트 좌석 모니터링

## 프로젝트 개요

**SCO 블랙관 스마트 좌석 모니터링**은 ADT 캡스 출입 기록(.mdb)을 실시간으로 연동하여 블랙관 좌석의 착석 상태를 시각적으로 파악할 수 있는 로컬 데스크톱 애플리케이션입니다.
서버 유지비용 없이 원장님 PC에서 영구적으로 단독 구동되는 환경을 구축하는 것을 목적으로 합니다.

- **저장소:** `sco-black-seat-monitor` (GitHub Public Repository)

## 주요 기능 및 특징

### 1. 좌석 상태 시각화

- **상태 구분:** 출입 기록을 바탕으로 입실(초록색), 미입실/퇴실(빨간색) 상태를 직관적으로 구분합니다.
- **UI 컴포넌트:** 좌석 번호 배열을 뱃지(Badge) 형태의 내부 컴포넌트로 모듈화하여 렌더링합니다.

### 2. 드래그 앤 드롭 (Drag & Drop) 이동 관리

- 입실 처리된 학생(초록색 좌석 뱃지)을 마우스로 드래그하여 **라운지존, 코칭/상담실, 스탠딩 책상, 다이닝룸** 등 특수 구역에 드롭할 수 있습니다.
- 이동 시 라운지존 등의 해당 좌석에 학생의 번호가 표시되어 실시간 위치 파악을 지원합니다.

### 3. 실시간 데이터 연동의 안전성 보장

- 주기적으로 ADT 캡스 출입 데이터 파일(`.mdb`)을 조회합니다.
- 캡스 시스템과의 파일 점유(Lock) 충돌을 방지하기 위해 원본 파일을 다른 경로로 안전하게 복사한 후 데이터를 추출합니다.

### 4. 사용자 편의 공통 UI

- 화면 상단에 현재 날짜와 시간(24시간 형식)을 배치하고 1분 주기로 업데이트하여 표시합니다.
- 리스트나 로그가 길어질 경우를 대비해 화면을 최상단으로 올릴 수 있는 **스크롤 맨 위로** 버튼을 탑재했습니다.
- 모바일, 태블릿, 데스크톱 등 환경에 구애받지 않고 창 크기 조절 시 원활하게 작동하는 **반응형 UI**를 제공합니다.

## 구역 및 좌석 배치 구성

- **총 좌석 수:** 총 94석 (1번 ~ 94번)
- **주요 공간 및 구역:** 코칭/상담실, 학습운영실, 집중존, 집중실 1~4, OA 사물함, 라운지존, 다이닝룸
  _(실제 공간 구획에 맞게 프론트엔드 화면 상에서 좌석을 시각적으로 렌더링합니다.)_

## 기술 스택

| 구분                | 기술 스택                                                                                                                         | 역할 및 선정 사유                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Frontend (UI)**   | React 19 (TS), Vite 8, Tailwind CSS v4, Daisy UI 5, Pretendard, SweetAlert2, Lucide React, **dnd-kit (또는 react-beautiful-dnd)** | 좌석 배치도, 상태 관리, 뱃지 렌더링, 라운지존 이동을 위한 드래그 앤 드롭 구현 및 반응형 모던 UI 구축 |
| **Desktop Runtime** | Electron                                                                                                                          | React로 구현된 화면을 로컬 `.exe` 실행 파일로 패키징하여 서버 없는 단독 구동 환경 제공               |
| **Database**        | Node.js (`node-adodb`)                                                                                                            | Electron 백그라운드 환경에서 로컬 `.mdb` 파일에 접근하여 쿼리 실행                                   |

## 기대 효과 및 제약 사항

### 기대 효과

- 원장님 PC 단독 실행으로 클라우드 호스팅이나 외부 서버 **유지보수 비용이 영구 면제**됩니다.
- 실행 파일 하나로 관리가 종료되며, 라운지존 이동 상태까지 직관적으로 관리할 수 있습니다.

### 제약 사항

- 원장님 PC가 켜져 있고 ADT 캡스 프로그램이 정상 구동되어 `.mdb` 파일이 갱신되는 상황에서만 최신 상태 확인이 가능합니다.
